# Supex Group Inc website

Static company website for LED lighting, consumer electronics, and accessories. Hosted on GitHub Pages with the custom domain `supexinc.com`.

## Editing content

- `index.html`: company copy, categories, and contact email.
- `styles.css`: desktop and mobile styles.
- `assets/led-catalog.png`: AI-generated illustrative LED category contact sheet, used through CSS image positions. It depicts generic product styles, not actual inventory.
- `assets/workspace.jpg`: original introductory photograph retained as an optional asset.
- `CNAME`: custom domain for GitHub Pages. Keep this file when updating the site.

The category examples are introductory, not claims about confirmed inventory. Product availability is confirmed by inquiry. No pricing, certifications, customer endorsements, or delivery guarantees are asserted.

## Preview

Run `python -m http.server 8000` in this directory and open the local URL. No build process is required.

## Deployment

In repository Settings → Pages, select Deploy from a branch, branch `main`, folder `/ (root)`. Set the custom domain to `supexinc.com` and enable HTTPS when the certificate becomes available.

## Lighting catalog update

LED lighting is the primary product section, with bulbs, strips, ceiling lights, downlights, panels, tubes, floodlights, high bays, solar garden lights, work lights, desk lamps, and night lights. A compact secondary section includes personal fans, portable blenders, charging accessories, and audio/phone essentials.

Category inspiration: https://www.globalsources.com/searchList/products?keyWord=led%20lights&pageNum=1 and Global Sources lighting category pages. No supplier images, prices, certifications, or product specifications were copied.
