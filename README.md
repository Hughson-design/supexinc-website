# Supex Group Inc website

Static company website for LED lighting, consumer electronics, and accessories. Hosted on GitHub Pages with the custom domain `supexinc.com`.

## Editing content

- `index.html`: company copy, categories, and contact email.
- `styles.css`: desktop and mobile styles.
- `assets/workspace.jpg`: illustrative hero photograph, not an actual product listing.
- `CNAME`: custom domain for GitHub Pages. Keep this file when updating the site.

The category examples are introductory, not claims about confirmed inventory. Product availability is confirmed by inquiry. No pricing, certifications, customer endorsements, or delivery guarantees are asserted.

## Preview

Run `python -m http.server 8000` in this directory and open the local URL. No build process is required.

## Deployment

In repository Settings → Pages, select Deploy from a branch, branch `main`, folder `/ (root)`. Set the custom domain to `supexinc.com` and enable HTTPS when the certificate becomes available.
